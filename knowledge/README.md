# Knowledge Base

This directory contains the accepted, citable knowledge of Puzzle Genome Atlas.
Exploratory leads and unresolved classification proposals belong in
[`research/`](../research/).

## Canonical collections

- [`genes/`](genes/README.md) — typed, reusable mechanic genes with stable IDs.
- [`games/`](games/README.md) — evidence-backed game decompositions.
- [`combinations/`](combinations/README.md) — verified structural combinations.

An entry can be revised when evidence changes, but its stable ID is never reused
for a different concept.
