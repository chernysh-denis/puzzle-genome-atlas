## Decision structure

One directional input transforms every movable line. Automatic merging can
recover occupancy capacity, then an unpreviewed random spawn consumes capacity
and changes the next decision.

## Combination match boundary

A game does not instantiate this combination merely because it contains
merging or random spawning. The globally coupled directional action, ordered
merge resolution, post-valid-action spawn and fixed-capacity pressure must all
remain decision-relevant.
