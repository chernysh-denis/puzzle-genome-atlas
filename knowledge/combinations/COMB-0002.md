## Decision structure

Each direct layer rotation stays inside the legally reachable state space and
has an exact inverse. The solver must compose these individually reversible
actions to reconstruct one specified arrangement while preserving or restoring
already achieved substructures.

## Combination match boundary

A system does not instantiate this combination merely because it contains
rotation or an undo command. Rotation must directly transform a coupled layer,
primitive actions must be structurally invertible, legal states must be
restricted by global reachability invariants, and reconstruction must be the
objective.
