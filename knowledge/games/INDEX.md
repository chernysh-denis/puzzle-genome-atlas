## Stable path shards

New files use a lower-case slug and one non-semantic shard:

- `0-9/`
- `a-f/`
- `g-l/`
- `m-r/`
- `s-z/`

Shards prevent a 1000-file directory without coupling paths to a taxonomy that
may later change.
