# Mission

## Goal

Build a defensible knowledge base of fundamental puzzle genes, classify their
known combinations and identify areas that remain weakly explored after
external research.

## Non-goals

- generating endless vague game ideas;
- calling a reskin a new mechanic;
- assuming that an empty matrix cell is automatically fun;
- claiming novelty without searching existing games;
- designing monetisation before proving the core loop;
- repeating the same theory in different words.

## Gate for a future candidate

A candidate should ideally have:

- rules explainable in under one minute;
- a small number of meaningful actions;
- a large state space;
- decisions with consequences for later decisions;
- visible and understandable feedback;
- room for player mastery;
- rapid restart or replay;
- multiple viable strategies or solution paths;
- suitability for a minimal prototype;
- no dependence on forced retention systems.

## Definition of novelty

Novelty does not mean a new visual theme.

A candidate is meaningfully novel only when the interaction between its typed
genes creates a decision structure not already common in existing games.

Absence from the current corpus is not evidence of novelty.
