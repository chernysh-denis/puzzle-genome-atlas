# Codex Operating Instructions

You are maintaining Puzzle Genome Atlas, an evidence-backed knowledge base of
fundamental puzzle mechanics.

## Canonical instructions

Do not restate project methodology here. Read and follow, in order:

1. [`README.md`](README.md) for orientation;
2. [`docs/RESEARCH_PRINCIPLES.md`](docs/RESEARCH_PRINCIPLES.md) for research
   constraints;
3. [`docs/EVIDENCE_MODEL.md`](docs/EVIDENCE_MODEL.md) for the only status and
   evidence scheme;
4. [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for canonical vocabulary,
   genome signatures and comparison mathematics;
5. [`CONTRIBUTING.md`](CONTRIBUTING.md) and the relevant template for the
   operational workflow;
6. [`docs/RESEARCH_PLAN.md`](docs/RESEARCH_PLAN.md) for the current subject.

Before changing knowledge, search the game, gene and combination indexes,
taxonomy changes and latest public research-log entry.

## Agent-specific safeguards

- Work as a researcher, not an idea generator.
- Do not force novelty, promote a parameter into a gene to obtain a positive
  result or treat theme as mechanics.
- Create a taxonomy-change record before changing a classification.
- Create a structured negative-result record only when evidence rejects a
  concrete prior claim, candidate or gene distinction. Otherwise write
  `Negative results: none` in the game analysis.
- Do not change architecture unless completed analyses expose a concrete
  integrity failure.
- Preserve earlier conclusions and explain revisions.
