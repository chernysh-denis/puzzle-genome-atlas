# Hypotheses and Taxonomy Changes

This directory contains auditable research proposals that should not be folded silently into established documents.

Taxonomy corrections use sequential filenames:

`TAXONOMY_CHANGE_001.md`, `TAXONOMY_CHANGE_002.md`, and so on.

Each proposal must preserve the old classification, present evidence and counterevidence, define the proposed boundary and identify downstream genome or matrix changes.

Use [`templates/TAXONOMY_CHANGE_TEMPLATE.md`](../../templates/TAXONOMY_CHANGE_TEMPLATE.md).
