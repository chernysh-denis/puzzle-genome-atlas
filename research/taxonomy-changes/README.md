# Taxonomy Changes

This directory contains auditable proposals that must not be folded silently
into the gene registry.

Taxonomy corrections use sequential filenames:

`TAXONOMY_CHANGE_001.md`, `TAXONOMY_CHANGE_002.md`, and so on.

Each proposal must preserve the old classification, present evidence and
counterevidence, define the proposed boundary and identify downstream gene,
genome and combination changes.

Use the
[`taxonomy-change template`](../../templates/TAXONOMY_CHANGE_TEMPLATE.md).
