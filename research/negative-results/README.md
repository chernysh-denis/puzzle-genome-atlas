# Negative Results and Superseded Research

This directory preserves structured negative results:

- disproven novelty claims;
- combinations with established equivalents;
- gene distinctions that collapsed into synonyms;
- candidates rejected for readability, agency or testability.

Each entry must state the original claim, status, evidence, reason for rejection
and affected stable IDs. Raw ideas and personal notes do not belong here.

An analysis with no rejected prior claim writes `Negative results: none`; it
does not create an empty record.
