# Game Analyses

Each file in this directory decomposes one puzzle into:

- player actions;
- automatic system behaviours;
- constraints;
- information and time models;
- objectives and failure;
- strategic and replay structure;
- a normalised mechanical genome;
- comparisons with every earlier analysis.
